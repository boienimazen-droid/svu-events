# دليل فعاليات الجامعة الافتراضية السورية

موقع عربي متجاوب لاكتشاف الفعاليات الجامعية، مبني باستخدام HTML5 وCSS3 وJavaScript وBootstrap 5 RTL.

## الصفحات

- `index.html` الصفحة الرئيسية
- `events.html` دليل الفعاليات والبحث والفلاتر
- `event.html` تفاصيل الفعالية حسب المعرّف
- `about.html` عن الدليل وقيمه
- `contact.html` نموذج التواصل والأسئلة الشائعة

## التشغيل والمشاركة

- فك ضغط المجلد كاملاً ثم افتح `index.html` مباشرة في متصفح حديث، أو ارفع المجلد إلى استضافة مواقع ثابتة.
- تستخدم الصفحات ملف `assets/js/main.bundle.js` المرفق، لذلك لا تحتاج إلى خادم محلي لتشغيل التنقل والفلاتر والفعاليات.
- يلزم اتصال بالإنترنت لتحميل Bootstrap والخطوط والأيقونات من مصادرها الخارجية. التشغيل المباشر لا يعني التشغيل دون إنترنت.
- عند تعديل وحدات JavaScript المصدرية، شغّل `node tools/build.mjs` من مجلد `web` لإعادة إنشاء الملف المجمّع. لا توجد حزم إضافية مطلوبة.

## التواريخ والتصنيفات

- بقيت تواريخ الفعاليات المسجّلة كما هي؛ تُشتق أسماء الأيام والشهور والسنة من `dateValue` لتجنّب التناقضات.
- تعرض الصفحة الرئيسية أقرب الفعاليات التي لم تنتهِ، مرتّبة حسب موعدها. تُحدَّد نهاية الفعالية وفق وقتها المسجّل بتوقيت دمشق.
- تبقى الفعاليات السابقة في الدليل للأرشفة، مع علامة انتهاء وإغلاق زر التسجيل.
- تعمل روابط موسيقى ومجتمع وتعليم مع خيارات الفلترة. لا تتضمن البيانات الحالية فعالية موسيقية، لذلك يعرض هذا التصنيف حالة عدم وجود نتائج.

## المظهر الفاتح والداكن

- يختار الموقع مظهر الجهاز افتراضياً، ويحتفظ باختيارك عند استخدام زر الشمس/القمر عندما يكون التخزين متاحاً.
- تُطبّق التفضيلات قبل تحميل التنسيق لتجنّب وميض المظهر الفاتح، وتتزامن عناصر Bootstrap مع المظهر المختار.
- يبقى شريط التنقل فوق الخلفية الداكنة بنص وأيقونات واضحة في كلا المظهرين، وتتغيّر ألوان البطاقات والنماذج والنوافذ المنبثقة مع المظهر.
